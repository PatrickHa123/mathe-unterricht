# Mathematik-Unterricht

Digitale Unterrichtsreihen für Mathematik an der Kaiserin-Augusta-Schule Köln.

## Struktur

- `jahrgang-5/` – Reihen für Jahrgang 5
- `jahrgang-6/` – Reihen für Jahrgang 6
- `jahrgang-7/` – Reihen für Jahrgang 7

Jede Reihe liegt als eigener Unterordner im passenden Jahrgang, z. B. `jahrgang-5/brueche/index.html`.
